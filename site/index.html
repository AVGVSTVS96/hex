A personal assistant that lives in your Telegram.

Built on Claude Code. It runs on your own always-on Linux box with your own Claude subscription, works in the background, and only messages you when it’s worth it.

Install GitHub

How it works

Every topic is its own session

General is your main assistant. Ask it to start something and it opens a new topic with a fresh Claude Code agent working on it. Close the topic when it’s done.

Telegram Your Linux box # Generalmain assistant # Landing pageClaude Code session # Backup scriptClaude Code session

It speaks up when it’s worth it

Every hour it checks your email, work it started in the background, threads waiting on you, and anything it promised to follow up on. If nothing needs you, you hear nothing.

Scheduled jobs live in a plain JSON file of cron entries, and only run while it’s idle.

  1. 10:45Nothing worth saying
  2. 11:45Nothing worth saying
  3. 12:45“Saw a Waymo receipt from 9:28…”
  4. 1:45Nothing worth saying
  5. 2:45Nothing worth saying

Its memory is files you can read

Everything it knows is plain text you can open and edit. Every conversation is saved as markdown, and each new session picks up where the last one ended.

How it works

Voice notes

Send one from wherever you are. It transcribes it and answers.

Keeps itself current

Its Telegram channel is a fork of Anthropic’s official Claude Code plugins. Every day a pipeline re-applies hex’s patches onto the latest upstream, Claude fixes any conflicts, and nothing ships unless the tests pass.

Install with one prompt

Paste this into Claude Code. Your coding agent sets up the rest.

Set up hex for me: https://github.com/AVGVSTVS96/hex. Follow INSTALL.md in that repo.

You’ll need

  • An always-on Linux box, like a home server or a cloud VM
  • A Claude subscription
  • Telegram

The only manual steps

  1. Create a Telegram bot with BotFather
  2. Create a forum group, a Telegram group with topics turned on
