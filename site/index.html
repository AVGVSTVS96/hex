What it does

heartbeat

Speaks up first

Checks your email and open work every hour. Quiet when nothing needs you.

computer

Has its own computer

A cloud desktop with Chrome. Logs in, clicks through and solves CAPTCHAs.

inbox

Has its own email

Signs up for things and reads its own verification codes.

accounts

Reaches your accounts

Connect them once through Executor. Every session can use them.

memory

Remembers in plain files

Markdown you can read and edit. It updates them as it learns.

voice

Hears voice notes

Talk from anywhere. It transcribes and answers.

updates

Keeps itself current

Rebuilds on the latest Claude Code plugins daily. Claude fixes conflicts. Ships only if checks pass.
